# util

Reusable utilities and design assets for [NamTheDev](https://github.com/NamTheDev).

## Bootstrap design system

[css/bootstrap.css](css/bootstrap.css) is the canonical shared theme override for keep and clipboard. The apps load Bootstrap 5.3.8 locally before this file, then use native component and utility classes with compact monochrome theme overrides. Both vendor identical copies in their shared stylesheet paths.

[css/README.md](css/README.md) documents usage. The historical Material Design stylesheet is retained for compatibility, but migrated apps no longer synchronize it.
